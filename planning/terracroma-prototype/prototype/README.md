# Prototype build folder

This folder contains implementation-ready build instructions and templates. It does not contain a working frontend/backend implementation.

Start with:
1. `../AGENTS.md`
2. `../plan/62-hackathon-mvp-build-specification.md`
3. `IMPLEMENTATION-BACKLOG.md`
4. `FEATURE-PRIORITY-MATRIX.md`
5. `SCREEN-ROUTES.md`

Copy `source-manifest.template.yaml` to your data directory and fill it only with verified products. `demo-study.template.json` contains null values deliberately; it must not be presented as measured science. Any synthetic demo values must be marked `synthetic_demo` and shown with a persistent UI label.
