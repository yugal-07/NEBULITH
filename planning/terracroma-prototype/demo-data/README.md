# Demo data policy

No fabricated scientific raster values are bundled here. Populate this folder only with small, verified, redistributable AOI extracts and a matching source manifest. Every asset must record provider, product/version, landing page, access date, CRS, units, spatial resolution, observation date, license/attribution, checksum and processing recipe.

For UI development, use clearly labelled `synthetic_demo` fixtures outside the scientific data store. Do not export synthetic fixtures as observed NASA/agency measurements.
